<h2 class="wp-block-heading">Let Your AI Coding Assistant Run Deployments (MCP Native)</h2>
<p class="wp-block-paragraph">One of the standout, industry-first innovations in Nivi Apps is deep support for the <strong>Model Context Protocol (MCP)</strong>. Instead of constantly context-switching between your terminal, cloud dashboard, and code editor, Nivi Apps bridges directly into leading AI coding environments including <strong>Claude, ChatGPT, Cursor, and Windsurf</strong>.</p>

<p class="wp-block-paragraph">Through our secure MCP connector, your AI assistant can interact with your application environment directly under your permission:</p>
<ul class="wp-block-list">
  <li><strong>Instant Error Diagnosis:</strong> If an app returns an HTTP 500 error or fails to boot, your AI assistant can inspect the last 100 lines of live application container logs, locate the syntax exception or missing environment variable, and suggest the fix right in your code editor.</li>
  <li><strong>One-Click Redeployments:</strong> After you accept a code change or bug fix, instruct your assistant: <em>"Redeploy the auth service on Nivi Apps,"</em> and it triggers the build pipeline automatically.</li>
  <li><strong>Container State &amp; Health Checks:</strong> Check status, restart unresponsive worker processes, and view CPU/memory telemetry without opening a browser window.</li>
  <li><strong>Granular Security Controls:</strong> The AI connector operates strictly within the permissions you grant and can only see the apps assigned to your authenticated API keys.</li>
</ul>

<h2 class="wp-block-heading">Key Platform Features Engineered for Developers</h2>
<p class="wp-block-paragraph">Nivi Apps eliminates operational friction while keeping full power in your hands:</p>

  <li><strong>Live Streaming Logs:</strong> View continuous standard output (stdout/stderr) from your application processes in real time to catch crashes, debug routing errors, and verify worker jobs.</li>
  <li><strong>Environment Variables Management:</strong> Configure API keys, database credentials, and production environment variables securely in your dashboard. Updating variables triggers seamless rolling updates.</li>
  <li><strong>Private Network Isolation:</strong> Every app runs on its own dedicated virtual network. Databases and internal services are kept private and shielded from the public internet, accessible only by your authorized frontends.</li>
  <li><strong>Automatic Self-Healing &amp; Restarts:</strong> If an unhandled exception or memory surge crashes your application process, the Nivi Apps container engine immediately spins up a healthy container instance to keep your downtime near zero.</li>
  <li><strong>Zero Vendor Lock-In:</strong> Because Nivi Apps runs standard Open Container Initiative (OCI) containers built from your clean Git repositories or Dockerfiles, you always retain 100% ownership of your code. You can move your application to any server anytime.</li>

<h2 class="wp-block-heading">Frequently Asked Questions (FAQ)</h2>

<h3 class="wp-block-heading">Do I need to know Docker to use Nivi Apps?</h3>
<p class="wp-block-paragraph">No. Docker knowledge is completely optional. When you deploy a repository or ZIP folder, Nivi Apps automatically detects the project framework (Node, Python, PHP, Go, etc.) and compiles the container for you. Dockerfiles are only necessary if you desire custom system dependencies.</p>

<h3 class="wp-block-heading">Can I deploy from a private GitHub repository?</h3>
<p class="wp-block-paragraph">Yes. You can securely authenticate your GitHub account or supply a private Git access token. Nivi Apps allows you to deploy from any branch and trigger automatic or manual builds on new commits.</p>

<h3 class="wp-block-heading">What happens if my application crashes or throws an exception?</h3>
<p class="wp-block-paragraph">Nivi Apps features automated self-healing. If a fatal crash occurs, the container is restarted immediately to minimize downtime. You can open live logs in the dashboard or have your AI assistant review the stack trace to diagnose the issue.</p>

<h3 class="wp-block-heading">Can I connect my own custom domain name?</h3>
<p class="wp-block-paragraph">Yes. You can attach any custom domain or subdomain by pointing an A or CNAME record to the server address in your dashboard. An SSL certificate is automatically provisioned and renewed at zero cost.</p>

<h3 class="wp-block-heading">Does Nivi Apps support databases?</h3>
<p class="wp-block-paragraph">Yes. You can spin up managed PostgreSQL, MySQL, MariaDB, or Redis database containers alongside your web applications. Connection strings and internal networking are configured automatically.</p>

<h3 class="wp-block-heading">Can I migrate my app somewhere else in the future?</h3>
<p class="wp-block-paragraph">Yes. Because Nivi Apps builds standard OCI containers directly from your codebase, there is zero proprietary vendor lock-in. You can take your repository and run it on any server or cloud environment anytime.</p>
